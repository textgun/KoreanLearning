# 기획서 상세 개정 계획

목적. 원본 PDF와 검토 권고를 바탕으로 서비스 운영 및 구현 판단에 사용할 상세 기획서를 작성한다.

1. 원본과 저장소 결정 기록을 대조한다. 검증은 기존 합의와 새 권고의 구분이다.
2. 첫 무료 수업 완료를 중심으로 계정, 연결, 예약, 학습, 안전 요구사항을 작성한다. 검증은 정상·실패 흐름의 연결이다.
3. 크레딧·취소·환불·정산 및 법률 확인 관문을 구체화한다. 검증은 중복 처리·악용·분쟁 시나리오다.
4. Markdown과 PDF를 만든다. 검증은 내용 일치, 한글 추출, 전체 페이지 렌더링 및 시각 검수다.
5. 문서 변경을 의미 단위로 커밋한다. 앱 소스와 운영 설정은 이번 문서 작업 범위가 아니다.
