# 강사 신청 실제 접수 구현 계획

클로드가 반영한 디자인을 보존하고 Firebase 기반 실제 접수 기능을 준비한다.

1. 기존 변경과 승인 정책을 검토하고 설정을 한곳에 기록한다.
2. 이메일 인증 사용자만 접수하며 본인/관리자만 열람하는 서버 API와 규칙을 구현한다.
3. 관리자 승인·보류·반려, 승인 시 기존 강사 권한 연결, 90일 만료 삭제를 구현한다.
4. 운영자 메일 알림은 서버 SMTP로 보내며 수신처를 변경 가능한 설정으로 둔다.
5. 신청/관리 화면을 연결하고 에뮬레이터·회귀 테스트·빌드로 검증한다.
6. 서버 배포/메일 인증이 없는 상태에서는 실제 접수를 열지 않는다. 배포 절차와 남은 관문을 기록한다.
