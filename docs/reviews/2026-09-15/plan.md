# 프로젝트 검토 계획

작성일. 2026-09-15.

## 목적과 범위

현재 저장소 전체를 대상으로 실제 오류, 접근 권한, 데이터 유실, 학습 흐름을 검토한다. 검토 요청으로 해석하며 애플리케이션 수정과 외부 서비스 변경은 수행하지 않는다.

## 순서와 완료 기준

1. 구조, 기존 작업 기록, 빌드와 테스트 구성을 확인한다. 확인 기준은 진입점과 데이터 흐름을 설명할 수 있는 것이다.
2. 인증·권한, 저장·동시 편집, 학생·교사 화면을 나누어 검토한다. 확인 기준은 각 문제의 조건과 영향, 코드 위치가 구체적인 것이다.
3. 로컬에서 문법 검사, 격리된 빌드, 필요한 최소 재현을 수행한다. 실제 Firebase 데이터는 변경하지 않는다.
4. 확인된 문제와 검증 한계를 보고서에 남기고 중요도순으로 전달한다.
