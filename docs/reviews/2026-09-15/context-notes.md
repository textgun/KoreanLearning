# 프로젝트 검토 컨텍스트

- 2026-09-15. 검토 시작 시 작업 트리는 깨끗하며 기준 커밋은 `f9ea601`이다.
- 프레임워크나 패키지 매니저 없이 브라우저 JavaScript를 Python으로 단일 HTML에 합치는 구조다.
- 기존 루트 체크리스트와 컨텍스트 노트는 과거 작업 기록이므로 보존하고 이번 기록은 날짜별 폴더에 둔다.
- 실제 서비스에 로그인하거나 데이터를 생성하지 않고 로컬 코드와 격리된 재현으로 검토한다. 배포된 Firestore 규칙과 운영 데이터 상태는 저장소만으로 확정할 수 없다.
- 인증·규칙, 교사 편집·AI 변환, 학생 게임은 독립 검토로 분담하고 저장 계층과 빌드는 주 검토자가 확인했다.
- `_mergeWithServer`는 새 ID만 합치므로 서로 다른 기존 단원을 편집해도 변경이 유실된다. 기존 작업 기록의 '같은 단원 동시 편집만 남음'이라는 판단과 달라 별도로 재현했다.
- 저장이 진행 중일 때 후속 요청을 버리고, 학생 저장 재시도는 전역 점수를 다시 읽는다는 두 문제를 분리했다. 해결책도 저장 대기와 대상·데이터 고정으로 다르다.
- 소스 9개와 빌드 인라인 스크립트 2개 문법 검사, 격리 빌드는 통과했다. 원본 배포 HTML은 갱신하지 않았다.
- 실제 함수에 대역 저장소·타이머를 연결한 재현으로 검토했다. 게임 DOM은 모의 구현이며 실제 브라우저 통합 검증과 구분한다.
- 로컬 Chrome은 환경의 소켓 제한으로 시작에 실패했다. 카드 HTML 삽입 문제는 코드 경로 확인 수준으로 보고한다.
