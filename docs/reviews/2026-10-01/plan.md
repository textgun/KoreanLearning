# 프로젝트 2차 검토 계획

작성일. 2026-10-01.

## 목적과 범위

1차 검토(2026-09-15) 이후의 상태를 확인하고, 1차에서 다루지 않은 문제를 찾는다. 검토 요청으로 해석하며 애플리케이션 수정과 외부 서비스 변경은 하지 않는다.

## 순서와 완료 기준

1. 1차 이후 변경 내역을 확인한다. 기준은 1차 항목의 해결 여부를 판단할 수 있는 것이다.
2. 전체 소스를 다시 읽고 1차와 겹치지 않는 문제를 찾는다. 기준은 위치·조건·영향·조치가 구체적인 것이다.
3. 문법 검사, 격리 빌드, 실제 함수를 쓰는 최소 재현을 수행한다. 실제 Firebase 데이터는 건드리지 않는다.
4. 결과를 `review.md`에, 재현 코드를 `repro.js`에 남긴다.
