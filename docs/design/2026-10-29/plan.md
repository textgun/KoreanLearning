# 말이음 강사 신청 화면 계획

랜딩페이지와 같은 시각 언어로 기본 정보 → 수업 소개 → 내용 확인의 신청 시안을 만든다. 입력 내용은 메모리에서만 사용하며 실제 접수·저장은 하지 않는다.

1. 기존 CSS와 사진을 재사용해 반응형 신청 화면을 구현한다.
2. 필수값 검증, 단계 이동, 수정, 시안 완료 화면을 연결한다.
3. 랜딩페이지 CTA와 공개 빌드를 연결하고 폼 회귀 테스트·기존 테스트·빌드를 확인한다.
4. 공개 배포 후 화면 및 신청 흐름을 검증한다.

## 공개 화면 다듬기

사용자 요청으로 시안·체험 표현을 제거하고 자연스러운 서비스 문구로 다듬는다. 실제 접수 기능이 없다는 사실은 접수 준비 중 표시와 저장·전송 안내로 유지한다. 기존 테스트와 빌드 후 공개 배포한다.
