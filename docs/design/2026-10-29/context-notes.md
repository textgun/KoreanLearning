# 컨텍스트 노트

- 사용자는 후속 신청 화면을 랜딩페이지와 비슷한 분위기로 요청했다.
- 크림색, 브라운 글자, 노랑 CTA, 초록 포인트와 기존 인물 사진을 재사용한다.
- 아직 실제 신청 항목·승인 기준·개인정보 정책이 확정되지 않았다. 개인정보 저장과 실제 접수는 구현하지 않는다.
- 이름·이메일·수업 가능 언어·교육 경험·자기소개만 시안 입력 항목으로 사용한다. 브라우저 저장소 및 네트워크 전송은 사용하지 않는다.
- 완료 문구는 실제 접수와 혼동하지 않도록 시안 체험 완료로 표기한다. 입력 시작 전에 저장·전송하지 않는 시안임을 안내한다.
- 기존 공개 URL 공유 요청에 이어 같은 GitHub Pages의 /teacher/apply.html로 제공한다.

## 검증

- 최초 회귀 테스트가 경험 선택 항목의 option 여는 태그 누락을 발견했다. 실제 DOM의 선택지 목록으로 원인을 확인하고 수정했다.
- 신청 회귀 테스트 및 기존 클라이언트 테스트 통과. 빈값·공백·잘못된 이메일, 단계 이동, 수정 보존, HTML 문자열의 텍스트 표시, 초기화 확인.
- 임시 디렉터리에서 전체 빌드 성공. 랜딩/신청 HTML의 로컬 링크와 자산 존재 확인.
- 실제 브라우저에서 예시 데이터로 3단계 및 시안 완료·다시 시작 확인. 모바일 390px 뷰포트에서 콘텐츠/스크롤 너비가 모두 375px로 가로 넘침 없음.
- 기존 안내 대화상자는 신청 페이지 링크로 대체했고 사용하지 않는 teacher-landing.js를 제거했다.

- 커밋·push 명령의 권한 요청이 사용자에 의해 거절되어 실행되지 않았다. 공개 배포는 미완료이며 로컬 변경으로 남겨 두었다.
- 로컬 미리보기 http://127.0.0.1:8766/Concept/apply.html, 캡처 application-preview.png.

- 사용자가 시안 표시를 다듬어 공개 배포하도록 새로 승인했다. 이전 권한 거절 이후 새 배포 요청이다.
- 접수 시스템은 여전히 미연결이다. 시안 대신 접수 준비 중으로 안내하며, 최종 동작은 제출이 아닌 작성 마치기다.

- 공개용 문구 개정 후 신청 회귀 테스트·기존 클라이언트 테스트 및 임시 전체 빌드 통과. 시안/체험 노출 없음과 접수 준비 중 안내를 테스트에 추가했다.
