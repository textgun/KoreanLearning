# 학습 앱 말이음 톤 개편 계획

처음 만든 학습 앱(`src/`)을 교사 랜딩페이지(`Concept/teacher-landing.*`)와 같은 톤앤매너로 다시 만든다. 사용자 결정에 따라 앱 전체 색·글꼴·버튼·카드를 랜딩 톤으로 맞추고, 메인과 학습 활동 전부는 배치까지 새로 짠다.

- 메인. 로그인·회원가입·비밀번호 찾기·승인 대기, 홈(모드 선택·선생님 소개), 학생 선택, 학생 단원 목록과 리더보드.
- 학습. 단원 화면(문법·활동 목록), 활동 9종(단어카드·4지선다·매칭·선잇기·받아쓰기·빈칸·문장 순서·OX·PDF 퀴즈), 결과 화면.
- 교사 관리·관리자 화면은 배치는 그대로 두고 색만 새 체계로 바꾼다.

1. 색·글꼴 토큰을 랜딩과 같게 바꾸고, 기존 변수 이름은 새 색을 가리키게 한다. 화면 코드에 박힌 인디고·회색 hex도 새 토큰으로 옮긴다.
2. 메인 화면을 랜딩의 영문 라벨·노란 밑줄 제목·크림 카드 구성으로 다시 짠다.
3. 학습 화면을 같은 구성으로 다시 짠다. 기능과 점수 로직, 화면 문구는 바꾸지 않는다.
4. `npm test`, 임시 빌드, 브라우저에서 375·820·1440px 화면을 확인하고 의미 단위로 커밋한다. 배포(push)는 사용자 확인 후 한다.
