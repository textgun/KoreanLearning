# 말이음 랜딩·신청 화면 검토 반영 계획

2026-10-30 검토에서 나온 항목 중 코드로 고칠 수 있는 것을 모두 반영한다. 사진 라이선스 확인과 신청 폼 방향(저장 여부)은 사용자 결정 사항이라 이번 범위에서 제외한다.

1. 좁은 화면의 ✳ 장식 겹침과 모바일 신청 제목 띄어쓰기를 고친다.
2. 수업 카드에서 히어로와 겹치는 사진 2장을 안 쓰던 사진으로 바꾸고 빌드 복사 목록에 추가한다.
3. 작은 글씨를 키우고 WCAG 4.5:1에 못 미치는 글자색을 고친다.
4. 링크처럼 보이는 카드 화살표·확대 효과와 사용하지 않는 CSS를 정리한다.
5. 띄어쓰기·조사·호칭 문구를 다듬고 모바일에서도 메뉴를 보여 준다.
6. 테스트·빌드·브라우저 화면(1440/820/375px)을 확인하고 의미 단위로 커밋한다. 공개 배포(push)는 사용자 확인 후 진행한다.
