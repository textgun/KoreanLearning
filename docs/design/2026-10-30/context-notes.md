# 컨텍스트 노트

- 사용자가 Codex 시안 검토 결과를 "전부 다 고쳐줘"로 승인했다. 사진 라이선스와 신청 폼 저장 여부는 코드로 정할 수 없어 사용자 결정으로 남긴다.
- 검토 시 확인한 버그. 1050px 이하에서 `.spark-one`(z-index 2)이 `.hello` 말풍선 글자를 덮는다(375·820px 확인, 1200px은 가장자리만 걸침). 모바일 신청 제목은 숨긴 `<br>` 양옆에 공백이 없어 "선생님의이야기부터."로 붙는다.
- 사용 중인 사진은 736px 폭·해시 파일명으로 Pinterest 출처로 보이나 확인하지 못했다. `eaa88d…jpg`는 다른 회사 광고 포스터라 쓰지 않는다.
- 명도 대비 계산 결과 `--muted`(#786b61)는 종이색 4.78:1이지만 수업 섹션 배경(#eeeae0)에서 4.29:1이다. 토큰을 #72655b로 조정하면 주요 배경 모두 4.5:1 이상이다.

## 결정

- ✳ 겹침은 말풍선에 z-index 3을 주고, 1050px 이하에서는 ✳를 말풍선 왼쪽 뒤로 옮겨 일부만 보이게 했다. 말풍선 위로 올리면 글자를 가리고, 숨기기만 하면 모바일에서 장식이 사라지기 때문이다.
- 수업 카드 1·3번 사진은 `5f5fd7…jpg`(도서관), `bb648d…jpg`(책 든 학생)로 바꿨다. 히어로·신청 페이지의 선생님 사진은 그대로 둔다. 새 사진 2장도 출처 미확인이라 라이선스 확인 대상은 모두 5장이다.
- 글씨는 장식용 영문 eyebrow 10~11px, 보조 한글 12~13px, 본문 14px 이상을 기준으로 맞췄다. 커진 글씨 때문에 "구성/해요"처럼 단어 중간 줄바꿈이 생겨 body에 `word-break:keep-all`을 추가했다.
- 글자색은 `--muted`를 #72655b로 바꾸고 하드코딩 회색(#998a7e, #8c8074, #817569, #91867a, #9b9085)을 토큰으로 통일했다. 옅은 초록 배경 위 초록 글자 2곳은 #326852(5.1:1 이상)로 바꿨다.
- 수업 카드는 링크 대상이 없어 화살표와 확대 효과를 지웠다. 역할 호칭은 "강사", 부르는 말은 "선생님"으로 나눴다.
- 모바일 메뉴는 JS 없이 헤더를 줄바꿈해 두 번째 줄에 3개 링크를 보여 준다.

## 검증

- 신청 회귀 테스트 1/1, 기존 클라이언트 테스트 12/12 통과.
- 임시 디렉터리 전체 빌드 성공. dist/teacher의 HTML 참조 경로 모두 존재, 사진 5장 복사 확인.
- 320·375·820·1440px에서 랜딩·신청 페이지 가로 넘침 없음. 헤드리스 크롬 캡처로 ✳·말풍선, 카드 사진, 모바일 메뉴, 신청 제목 띄어쓰기 확인.
- 공개 배포(push)는 하지 않았다. 사용자 확인 대기.
