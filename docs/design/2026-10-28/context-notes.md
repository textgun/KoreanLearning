# 컨텍스트 노트

- 요청은 Concept 이미지를 사용하는 교사용 랜딩페이지 시안이다. 교사 모집 목적의 독립 HTML로 해석했다.
- 기존 앱은 Python 병합 빌드를 쓰는 Firebase 앱이다. 시안은 Concept/teacher-landing.html로 분리한다.
- site idea 이미지는 색상과 구성의 참고 자료이며, charater 폴더의 원본 사진을 직접 참조한다.
- 한국어 전파를 중심에 두되 실적·후기·수익 숫자는 만들지 않는다. 인물은 실제 등록 교사로 표시하지 않는다.
- 참여 버튼은 실제 신청을 받지 않는 시안 안내 대화상자를 연다. FAQ는 기본 details 요소를 사용한다.

## 검증 결과

- npm run test:client 통과. 1개 테스트 파일 성공, 실패 0.
- node --check 통과, HTML의 로컬 이미지·스타일·스크립트 경로 모두 존재.
- 임시 디렉터리에 src와 build.py를 복사하여 기존 앱 빌드 성공. 운영 산출물 변경 없음.
- 브라우저에서 이미지 5개 로드, 참여 대화상자 열기·닫기 및 FAQ 펼치기 확인.
- 390px 뷰포트에서 콘텐츠 너비와 스크롤 너비 모두 375px로 가로 넘침 없음. 검증 후 원래 뷰포트 복구.
- 전체 페이지 화면은 preview.png에 저장. 로컬 미리보기는 http://127.0.0.1:8766/Concept/teacher-landing.html.
- 브랜드 한글로는 시안용 임시 명칭이다. 실제 서비스 이름 변경은 적용하지 않았다.
