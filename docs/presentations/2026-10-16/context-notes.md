# 발표자료 맥락

- 사용자는 상세 기획서를 심플한 그래픽을 포함한 발표자료로 요청했고 교육용 발표 디자인 이미지를 제공했다.
- 15장, 16:9, 한국어, 기획 공유 목적을 기본으로 한다. 아동 사진·타사 로고·예시 통계는 가져오지 않는다.
- 참고 색상과 둥근 구성을 반영하되 성인 한국어 학습 플랫폼의 내용으로 작성한다.
- 1:1·30분 등 미정값은 권고로 표시한다. 지표 목표값은 확정 성과처럼 표현하지 않는다.
- 편집 가능한 PPTX와 보기용 PDF를 만든다. 임시 렌더와 검증 기록은 빌드 폴더에 둔다.

## 최종 검수

- PPTX 15장, PDF 15쪽. 전체 슬라이드 렌더와 PDF 변환 결과를 비교했다.
- 파일 구조·배치·글꼴 검사 오류 0건, Artifact Tool 재열기 통과. PowerPoint 앱에서 직접 실행한 검사는 아니다.
- Artifact Tool의 PDF 출력은 Helvetica 모듈 누락으로 실패해, 최종 PPTX를 LibreOffice로 PDF 변환했다.
- 발표자 노트에 상세 기획서의 해당 절과 주요 전제를 기록했다.
- 표지 이미지 생성은 내장 image_gen을 사용했다. 이미지 경로는 assets/learning-illustration.png이며 PPTX에도 포함했다.
- 생성 프롬프트. 크림색 16:9 배경, 왼쪽 55%는 제목을 위한 여백, 오른쪽에 성인 학습자와 교사의 온라인 수업 및 노트북·책, 초록·코랄·노랑·남색의 간단한 편집 일러스트, 글자·로고·아동·사진 없음.
